How this fits together

This page writes to your browser's local storage. After uploading data here, click Export updated dataset and commit the downloaded JSON files into assets/data/ in the repo, then push — that's what refreshes the public Overview, Store Cohort and Trend pages. If you opened this page directly from a downloaded file (a file:// address), uploads won't load existing data correctly — see the README for how to run it via a tiny local server instead.

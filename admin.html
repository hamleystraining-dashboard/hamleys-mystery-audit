This is the permanent fix for "I see it, my colleague doesn't": clicking this pushes your changes straight to the live GitHub Pages site — no downloading files or dragging them into GitHub by hand, and nothing gets forgotten. It's still one person's action publishing for everyone (that's the right model for this data — it's periodically updated by L&D, not something many people edit at once), it's just no longer a manual multi-step process someone can skip.

First time? How to get a token
  1. Go to github.com/settings/personal-access-tokens/new (log in as whichever GitHub account owns the repo)
  2. Repository access → "Only select repositories" → choose hamleys-mystery-audit
  3. Permissions → "Repository permissions" → set Contents to Read and write (leave everything else as "No access")
  4. Click Generate token, then copy it (starts with github_pat_...) — GitHub only shows it once
  5. Click Publish directly to GitHub above and paste it in when asked

The token is kept only in this browser tab's memory for this session — it's never written to any file, never committed, and disappears when you close the tab (or click "Forget saved token"). Scope it to just this one repository, and only give Contents write access, so even if it leaked it couldn't do much.

Manual fallback

If you'd rather not set up a token, this still works exactly as before: download the files, then drag them into GitHub yourself.
